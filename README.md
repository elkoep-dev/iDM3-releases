# iDM3

iDM3 (iNELS Design Manager) is the software for designing, programming and commissioning
**iNELS BUS** installations by ELKO EP. With it you add the central unit and bus units to a
project, set up their functions and logic, upload the project to the CU3 central unit,
monitor the installation and update the firmware of its devices.

## Download

Download the installer of the latest version from [Releases](../../releases/latest) and run
it. No administrator rights are needed.

iDM3 3.7 and later checks for new versions and device firmware itself and offers them on
its Overview page.

## Documentation

[iDM3 on the iNELS wiki](https://wiki.inels.com/inels-bus/inels-design-manager-idm3)

## About this repository

This repository hosts the iDM3 installers, the device firmware and the catalogue iDM3
downloads updates from. Firmware listed in `withdrawn-firmware.txt` is no longer offered.
